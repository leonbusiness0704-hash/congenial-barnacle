# UGC Template

## 1. Templates

Wähle pro Skript ein anderes Template (passend zu Produkt und Zielgruppe),
außer der User nennt eins.

**T1 Problem → Lösung**
Hook: Problem in einem Satz → Frust zeigen → "Dann hab ich [Produkt] gefunden" → Demo → Ergebnis → CTA

**T2 Skeptiker**
"Ich war mir sicher, dass [Produkt] Quatsch ist." → Warum skeptisch → Test → Überraschung → Ehrliches Fazit → CTA

**T3 3 Gründe**
"3 Gründe, warum ich nie wieder ohne [Produkt] …" → Grund 1, 2, 3 (stärkster zuletzt) → CTA

**T4 Storytime**
"Storytime: [Situation]" → Spannung → Wendepunkt durch Produkt → Ergebnis → CTA

**T5 Us vs. Them**
"Hör auf, [übliche Alternative] zu benutzen." → Was daran nervt → Unterschied → Beweis → CTA

**T6 Vorher/Nachher**
"Tag 1 vs. Tag [X]" → Ausgangslage → Routine → Ergebnis (ehrlich, keine Heilversprechen) → CTA

**T7 Geheimtipp**
"Das ist das [Produktkategorie], das niemand kennt." → Was es macht → Warum besser → Preis/Angebot → CTA

**T8 Reaktion / Unboxing**
"Okay, es ist endlich da." → Auspacken → Erster Eindruck → Test → Fazit → CTA

**T9 Einwand-Killer**
"Ist [Produkt] es wirklich wert?" → Einwand 1 (Preis) → Einwand 2 (funktioniert es?) → Garantie → CTA

**T10 POV**
"POV: du [Situation der Zielgruppe]" → Szene → Produkt löst sie → CTA

## 2. Ausfüllen

- Platzhalter mit konkreten Details aus dem Brief füllen, nicht generisch lassen.
- Template-Struktur einhalten, Formulierungen frei anpassen.
- Pro Skript oben angeben: `Template: T3 3 Gründe`.
